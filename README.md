# Motivation-Study-Timer
I need to work on my writing speed and time taken for different questions on my English GCSE. This should help... Also, it keeps you motivated during those horribly long essays that your teachers set you for homework.

## Parts used:
- Raspberry Pi Pico W with headers
- EC11 Rotary encoder with push button
- 0.91in OLED I2C display
- PCB made with files provided in the "PCB" folder
